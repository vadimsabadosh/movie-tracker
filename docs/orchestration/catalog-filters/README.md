# Оркестрація: фільтри й сортування каталогу, постери в історії (FR-5, FR-9)

Шоста повна оркестрація Planner → Coder → Reviewer і друга після курсу.

Каталог (`GET /movies`, екран `#/`) отримав:
- **фільтри:** жанр (випадний список із нового `GET /genres`), діапазон років, режисер (частина імені) і статус перегляду;
- **сортування:** популярність (голоси IMDb, типово), рейтинг IMDb, рік, назва;
- **на екрані:** рядок «IMDb 9.3 · 3 264 230 votes» і позначку «Watched».

Також:
- сторінка фільму показує рейтинг IMDb;
- історія отримала постери, а її фільтр жанру теж став випадним списком;
- міграція 4 додала `imdb_rating`, `imdb_votes` і `director_key`;
- повторний запуск `npm run import:imdb` заповнює рейтинги.

`Movie` і `src/recommendation/` (W5) не змінено.

## 3. Збереження контексту

- **Відповіді людини, що відрізнялися від рекомендацій (Q5–Q7), не пішли напряму до Coder.** Їх повернули Planner, і він випустив rev 2 з новими рішеннями (D11–D15) та їхніми причинами. Без цього Coder сам вирішував би, як показати рейтинг на сторінці фільму, не торкнувшись W5.
- **Причина D8/D12** (не змінювати `Movie`, бо від нього залежить W5) дійшла до тестів: Coder додав точну перевірку ключів `movie` у рекомендаціях, тож витік нових полів зламає збірку.
- **Уроки posters спрацювали:**
  - обидві W3-правки пройшли через Edit і записані в лог;
  - браузерна перевірка до рев'ю дала Reviewer докази вже в раунді 1, тому UI-вади не довелося шукати після схвалення.
- **Де контекст губився:** у плані не знайдено. Друга причина нерівних підписів (відступ `.card`) не була в жодному handoff: її знайшов Coder під час виправлення F2.

## 6. Відкрите

- **Кандидати ADR з `03-review.md`:**
  - доповнення до ADR-011 (виміряно на 20 000 фільмів);
  - рейтинг і голоси IMDb як імпортовані дані з `NULL`;
  - `CatalogMovie` розширює `Movie`;
  - бекфіл у міграції через JS-функцію;
  - контракт `GET /genres`;
  - булеві прапорці як `z.enum`.

  Їх треба записати, коли vault MCP підключиться.
- **Людині:**
  - перезапустити `npm start`, бо працює код, запущений до міграції 4;
  - запустити `npm run import:imdb`, щоб з'явилися рейтинги (зараз у реальній БД 0 фільмів із рейтингом).
- Колонка фільтрів у 180 px переповнюється на екранах, вужчих за ~250 px.

# Оркестрація: опис фільму й актори з TMDB (FR-10)

Сьома повна оркестрація Planner → Coder → Reviewer і третя після курсу. Сторінка фільму показує сюжет і до 10 акторів з ролями з TMDB:

- **Лінивий пошук:** під час першого відкриття сторінки застосунок шукає дані в TMDB за IMDb ID через два документовані виклики, `/find` і `/movie/{id}/credits`, і зберігає їх (міграція 5: `overview`, `cast_json`).
- **Окремий ендпоінт:** `GET /movies/:id/details`. Сторінка малюється одразу, а опис та «Cast» з'являються, коли надходять дані.
- **Без токена чи мережі** сторінка виглядає як раніше.
- **Не змінено:** `Movie`, `CatalogMovie`, `GET /movies/:id` і `src/recommendation/` (W5).

Раунд 1 — і одразу APPROVE.

## 3. Збереження контексту

- **Прецедент posters перенісся майже дослівно.** Planner узяв конвенцію NULL/`''`, правило «збій не кешується», розділення 404/503 з окремим кодом «немає IMDb ID» і валідацію Zod на межі. Reviewer прямо порівняв `DetailsService` з `PosterService`.
- **Причина окремого ендпоінта** (сторінка не чекає TMDB, `CatalogMovie` не росте) дійшла до коду: UI не чекає на `/details`.
- **Уроки попередніх оркестрацій спрацювали:**
  - W3 через Edit, є в лозі;
  - тестовий сервер лише на `data/posters-test.db`, порт 3077, тож реальну БД цього разу не зачеплено;
  - браузерна перевірка до рев'ю, тож раунд 2 не знадобився.
- **Де контекст губився:**
  - Заборону B5 Coder отримав у задачі й плані, але все одно записав `server.ts` через heredoc. Правило було в handoff, а звичка «переписати файл з Bash» переважила.
  - Хук теж не спіймав порушення. Це вже друга прогалина того самого типу (після W3 у posters): хук не аналізує вміст Bash-команд, що пишуть файли.

## 6. Відкрите

- Кандидати ADR з `03-review.md`:
  - шаблон збагачення з TMDB (тепер два споживачі);
  - список для показу як JSON-колонка з CHECK;
  - окремі під-ресурси для повільних зовнішніх даних.

  Записати, коли підключиться vault MCP.
- Minor m1–m3 як дрібний наступний крок.
- Дві прогалини хука: запис файлів через Bash не бачать ні W3 (posters), ні B5 (тут).
- Людині: один живий перегляд сторінки фільму з токеном. Параметр `language` на `/find` і реальна форма `/credits` перевірені лише на фейках.

## 2. Що знайшов Reviewer

| ID | Суть | Як вирішено |
|---|---|---|
| F1 | Tie-break режисерів — бінарний порядок рядка, жанрів — `name_key` без регістру; для кирилиці рівні режисери «Борис» стоїть перед «андрій» | Відповідає D3/D5 і відповіді людини на Q2. Асиметрію записано в ADR-013 (Рішення, Наслідки), щоб FR-7/FR-8 на неї не натрапили |
| F2 | `const ids = []` у тесті — неявний `any[]`, звідси `ids[i]!` | Залишено: стиль у тесті, не блокує. Кандидат на прибирання разом із FR-7 |
| F3 | OpenAPI-тест не перевіряє поля `PreferenceItem` | Залишено: план вимагав лише наявність 200-відповіді; NFR-6 виконано |

## 3. Збереження контексту

- **Причини з плану дійшли до коду й тестів.** Відхилена в D3 альтернатива «tie-break за id» перетворилася на тест детермінованості, де другий БД заповнюється у зворотному порядку — так змінюються і id фільмів, і rowid переглядів. Reviewer прямо пов'язав цей тест із D3.
- **Coder посилив план, а не послабив.** Пара «Драма»/«комедія» з плану однаково впорядковується і за `name`, і за `name_key`, тож тест не зловив би регресію. Coder замінив її на «Комедія»/«драма», де порядки розходяться, і пояснив чому. Reviewer підтвердив, що це сильніше.
- **ADR-009 «без DISTINCT»** — у заголовку репозиторію і перевірено Reviewer через ключі схеми (`watches.movie_id` PK, PK `movie_genres`).
- **Де контекст міг загубитися:** F1 — Planner назвав порядок режисерів «за назвою», не уточнивши, що це бінарний порядок. Наслідок помітив лише Reviewer; тепер він в ADR-013.

## 6. Спостереження

- Нові перевірки NFR-4 (`npm run check`) підхопили обидві ролі: Coder запускав `format` → `check`, Reviewer перезапускав `check` сам. Інструкції ролей оновлено до старту (коміт `85bbdf6`), і їх продубльовано в промптах.
- Planner взяв з нотатки `Recommendation` приклад пояснення «середня оцінка 8.4» — звідти рішення залишити в API 2 знаки, а до 1 знака форматувати вже у FR-7.
- Профіль — вхід для FR-7: `ProfileService.get()` перевірено тестом на рівність HTTP-відповіді, тож наступна оркестрація може на нього покладатися.
